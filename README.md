# Quant Research Audit Lab

A compact, general-purpose statistics toolkit for time-ordered observations. Contains only synthetic sample data; no trading strategies, real positions, proprietary parameters or performance claims.

Features include cross-sectional rank information coefficient, moving-block bootstrap confidence intervals, Newey–West standard errors for a sample mean and a label-window-purged time split. These methods do not establish absence of overfitting or data leakage.

Run: `pip install -r requirements.txt`, then `python -m unittest -v` and `python demo.py`.
